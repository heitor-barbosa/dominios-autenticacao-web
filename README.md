# dominios-autenticacao-web

Projeto de uma aplicação Web de autenticação de usuários para a APS de Domínios de Software, UFG, semestre 2026/2.

## Equipe

- Brenner Rodrigues: frontend.
- Enzo Machado: arquitetura, documentação e consolidação da entrega.
- Heitor Barbosa: backend.

## Documentação

- [Planejamento](docs/Planejamento.md): divisão do trabalho e conferência da entrega de 27/10/2026.
- [Trabalho da APS](docs/Trabalho.md): ambiente operacional, arquitetura, componentes e referências.

A solução projetada usa HTML puro no frontend e JavaScript puro com Node.js no backend. O formulário envia as credenciais diretamente ao servidor. Os usuários ficam em um arquivo JSON local; a autenticação não inclui cadastro, sessão, logout ou área protegida.

O enunciado é `2026-2-Domínios de Software-Definição de APS.pdf`, localizado dois diretórios acima deste repositório. A entrega exigida é um único PDF. Os arquivos deste repositório documentam o projeto; não constituem uma implementação executável.
